"# SauceDemo Playwright Automation Architecture\n\n## 1. Technology Stack\n\n- Playwright Test with TypeScript\n- Page Object Model (POM)\n- Fixture-based dependency injection\n- CI-friendly artifacts: HTML, list, JUnit, trace, screenshot, video\n\n## 2. Current Project Layout\n\nsaucedemo-tests/\n- tests/\n  - login/\n  - products/\n  - cart/\n  - checkout/\n  - regression/\n- pages/\n  - LoginPage.ts\n  - ProductsPage.ts\n  - ProductDetailsPage.ts\n  - CartPage.ts\n  - CheckoutPage.ts\n- fixtures/\n  - testFixtures.ts\n- test-data/\n  - users.ts\n  - checkout.ts\n- utils/\n  - currency.ts\n- playwright.config.ts\n- TEST_PLAN.md\n- TEST_SCENARIOS.md\n- TEST_CASES.md\n\n## 3. Design Principles\n\n- Keep tests independent and deterministic.\n- Encapsulate UI actions in page objects.\n- Prefer role/label/text/testid locators.\n- Avoid hard-coded delays.\n- Keep data externalized and reusable.\n\n## 4. Fixture Strategy\n\n- Shared fixtures initialize page objects per test.\n- Static test-data fixtures expose users and checkout payloads.\n- Future enhancement: API seeding fixture if backend APIs are available.\n\n## 5. Locator Strategy\n\nPreferred order:\n1. getByRole()\n2. getByLabel()\n3. getByText()\n4. getByTestId()\n5. CSS only when necessary\n\n## 6. Execution Strategy\n\n- Parallel by default.\n- Retries: 1 local, 2 in CI.\n- Worker cap in CI to reduce resource contention.\n- Tagged subsets: @smoke and @regression.\n\n## 7. Reporting and Artifacts\n\n- Console list reporter for immediate feedback.\n- HTML report for rich analysis.\n- JUnit for CI dashboards.\n- Screenshot/video/trace on failures for fast debugging.\n\n## 8. CI/CD Integration Recommendation\n\n- Trigger smoke on pull requests.\n- Trigger full regression nightly and pre-release.\n- Publish HTML report as pipeline artifact.\n- Fail quality gates on smoke failure or Critical defect leakage.\n\n## 9. Future Enhancements\n\n- Accessibility assertions using axe-core.\n- API/UI hybrid checks for deterministic setup.\n- Visual baseline testing for high-value pages.\n- Synthetic performance trend checks per deployment.\n"
