"# SauceDemo Playwright Test Suite\n\n## Overview\n\nThis repository contains a maintainable Playwright + TypeScript automation framework for SauceDemo.\n\n## Prerequisites\n\n- Node.js 18+\n- npm 9+\n- Playwright browsers installed\n\n## Setup\n\n1. Install dependencies:\n   npm install\n2. Install Playwright browsers:\n   npx playwright install\n\n## Execution\n\n- Run all tests:\n  npm test\n- Run smoke suite:\n  npm run test:smoke\n- Run regression suite:\n  npm run test:regression\n- Run only Chromium:\n  npm run test:chromium\n- Open last HTML report:\n  npm run report\n\n## Key Files\n\n- TEST_PLAN.md\n- TEST_SCENARIOS.md\n- TEST_CASES.md\n- AUTOMATION_ARCHITECTURE.md\n- playwright.config.ts\n- pages/\n- fixtures/\n- test-data/\n- tests/\n\n## Notes\n\n- Base URL is configurable via BASE_URL environment variable.\n- Stable locators are prioritized using role, label, text, and data-test test IDs.\n- No hard-coded waits are used; tests rely on Playwright auto-waiting.\n"
